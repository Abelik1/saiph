# Reporting a security issue

Do not open a public issue containing vulnerability details, messages, device
keys, Firebase configuration or enrollment invitations. After the public
repository is available, use its Security tab and **Report a vulnerability**.
Maintainers must enable GitHub private vulnerability reporting before launch.

Private reporting is not yet enabled on a public Saiph Android repository. During
this preparation stage, contact the maintainer through the existing private
project conversation. No public security email address is claimed.

Beta builds have not received an independent security review. Permission handling,
background operation, sign-in, device approval and transport integration require
physical-device acceptance before release claims are made.
