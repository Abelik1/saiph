1. Install it

  1. Download the APK on your phone.
  2. Open the downloaded file. If Android says your phone isn't allowed to install from this source, tap Settings, turn on Allow from this source, go back and tap Install.
  3. If Google Play Protect warns you, tap More details, then Install anyway.
  4. Samsung: if the install is blocked, turn off Settings → Security and privacy → Auto Blocker, install, then turn it back on.

Already have another copy of Saiph? If Android refuses to install over it, uninstall that copy first, then pair the phone again.

2. Allow restricted settings

Android 13 and newer lock some settings for apps installed from outside Google Play. Do this once before the next step:

  1. Open Settings → Apps → Saiph.
  2. Tap ⋮ in the top corner, then Allow restricted settings, and confirm it's you.

If the option is missing, first try to turn on the setting in Saiph and let Android refuse once. The option then appears.

3. Sign in and pair

Open Saiph and continue with your Saiph account, or choose Self-hosted if you run your own Hub. Saiph Cloud needs a subscription or trial from your account.

Optional: commands for two extras

These need a computer and only need doing once. On the phone, tap Settings → About phone → Build number seven times, then turn on Settings → Developer options → USB debugging and connect the phone with a cable.

Background clipboard. Authorise this computer when the phone asks. Saiph then starts its own helper by itself. After a restart, Android may need debugging turned on again.

Sensitive notifications on Android 15 and newer. Android hides notifications such as one-time codes from other apps. To show them on your computer, run this with Android's platform tools:

adb shell appops set com.orionmini.mobile.unlocked RECEIVE_SENSITIVE_NOTIFICATIONS allow

Only do this if you're happy for those codes to appear on your computer. To undo it, run the same command with deny instead of allow.
