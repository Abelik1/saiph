Compare your file with its line in SHA256SUMS:

# Windows PowerShell
Get-FileHash -Algorithm SHA256 ./downloaded-file

# Linux
sha256sum ./downloaded-file

A checksum proves the file wasn't changed, not who published it. Don't skip signature warnings.
