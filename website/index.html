Saiph is in beta. Texts and calls need phone opt-in and Android permissions; the webcam needs USB or wireless debugging. Availability depends on device, OS version and region.

Requirements & sources Checked 18 October 2026
  1. Apple Continuity connects Apple devices signed in to the same Apple Account. Phone notifications on the Mac use iPhone Mirroring, which Apple currently lists as unavailable in the EU. See Apple feature requirements and Continuity and regional availability.
  2. Phone Link runs on Windows. With an iPhone it offers texts, calls and notifications only; photos, apps, file transfer and copy and paste are Android features. Android needs Android 10 or later and a Microsoft account. Cross-device copy and paste and file drag and drop work on select Samsung, HONOR, OPPO, ASUS, vivo and Xiaomi phones and Surface Duo. Calling uses Bluetooth; the phone camera needs Windows 11. See Phone Link requirements, copy and paste and file sharing, calls and phone camera.
  3. Saiph Cloud and a self-hosted Hub share the same apps and features. Notification replies, image copy and paste, MMS pictures and group replies now work on Saiph Cloud too, as beta features. See Cloud features and the self-hosting guide.

Call audio stays on the phone or its headset in both modes. These are beta features, with physical-device acceptance still pending.
