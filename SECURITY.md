# Security policy

Saiph is beta software. The latest beta and current development branch receive
security fixes; older previews have no promised support period. Hosted is planned,
and component encryption tests are not a claim that every shipping feature is
end-to-end encrypted or independently reviewed.

Report vulnerabilities through this repository's **Security → Advisories → Report
a vulnerability** form. Include affected versions, impact, reproduction steps
using synthetic data, and any proposed fix. Never attach real messages, enrollment
files, tokens, device keys or personal databases. Do not disclose exploit details
in public issues. If the private form is unavailable, open an issue requesting a
private security contact without including vulnerability details.

Maintainers will assess reports and coordinate fixes and disclosure with the
reporter. There is no guaranteed response deadline or paid bounty programme.

Before public launch, administrators must enable GitHub private vulnerability
reporting and subscribe to security notifications. A SECURITY.md file alone does
not enable the private reporting form. See [GitHub's reporting documentation](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately).
