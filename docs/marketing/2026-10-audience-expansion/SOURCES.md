## Art and motion

`website/assets/logo.svg` supplies the unmodified brand mark. `creative.js` embeds the same vector geometry so exported SVGs are standalone. Device silhouettes, bezels, cyan/violet palette and window chrome follow `website/assets/site.css`. Wave contours follow the vocabulary of `frontend/src/workspace/waves.tsx`, with deterministic motion added for advertising. The current app wave field is static.

The comic, original vector landscape, synthetic notes, link draft, notification, topology and cursor animation are authored locally. They are illustrations, not customer evidence or captured live-device results. No raster image generator, generative video model, stock media service, third-party creator likeness or external rendering API was used. SVGs contain their graphic geometry and text without remote images/fonts.

## Platform references

- [Google: About responsive search ads](https://support.google.com/google-ads/answer/7684791?hl=en): search headlines up to 30 characters; descriptions up to 90. The search CSV validates these limits and provides eight headlines/four descriptions per group.
- [Meta: Facebook and Instagram Reels ads](https://www.facebook.com/business/ads/facebook-instagram-reels-ads): vertical video format context. This pack supplies vertical motion and separate square/portrait artwork; actual placement preview and account approval remain outside this work.

No claim is made that one format is a proven winner, that an audience can be targeted exactly as described in a current ad interface, or that files are automatically approved for a placement. Distribution suggestions are test hypotheses and require an actual approved campaign scope.
